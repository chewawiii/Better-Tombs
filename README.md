# BetterTombs

**BetterTombs** is a Minecraft Bedrock add-on that adds protected gravestones when players die, allowing them to recover their items and experience safely.

Death no longer means losing everything without a trace. BetterTombs stores your items and XP in a tomb, protects it from intruders, and gives players configurable recovery options.

## Features

- Gravestones spawn when players die with items or experience.
- Recover lost items and XP from tombs.
- Tomb protection against intruders.
- Configurable intruder curses.
- Soul Fragment teleport item.
- Optional teleport confirmation.
- Optional death coordinate announcements.
- Configurable max tombs per player.
- Personal settings for players.
- System settings for operators.
- English and Spanish support.
